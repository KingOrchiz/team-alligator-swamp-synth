# Project plan

## Product

Alligator Swamp Synth is a compact three-voice instrument designed to demonstrate audio programming, expressive interaction, visual feedback, and clean OOP structure within the course workload.

## Milestones

- **14–16 Aug:** environment setup, repo workflow, minimal audio callback.
- **17–20 Aug:** three voice implementations and note mapping.
- **20–22 Aug:** mouse interaction and purposeful visualisation.
- **23–24 Aug:** integration, manual, learning log, AI disclosure, testing.
- **25 Aug:** release tag, clean ZIP, peer verification, LMS submission.

## Definition of done

- Three recognisably different voices work.
- Keyboard input works and panic stops audio.
- Mouse input produces audible and visible parameter changes.
- Visualisation represents generated audio or application state.
- Inheritance and composition are visible and explained.
- Both members test the release candidate.
- Both members have at least seven substantive Yellowdig posts/comments.
- Manual, learning log, GitHub link/stats, and AI-use declaration are included.
- Submission ZIP passes automated and manual review.
